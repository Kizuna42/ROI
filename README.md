# SaaS導入ROI分析システム

## 概要

SaaS製品導入の投資対効果を定量的にシミュレーションするReact/TypeScript製のSPAです。人件費・業務量・効率化率などの入力から、ROI・NPV・IRR・投資回収期間を算出し、コスト比較チャートや感度分析ヒートマップで可視化します。バックエンドを持たないクライアントサイド完結型のツールで、入力データはブラウザ内でのみ保持されます。

## 機能一覧

- **ROI入力フォーム**：基本情報（分析期間など）、人的リソース、業務量指標、追加コスト、初期投資、運用コスト、効率化指標、品質改善、その他便益を入力（react-hook-formによるバリデーション付き）
- **リアルタイム再計算**：フォーム値の変更を監視し、バリデーション通過時に自動でROI計算とサマリー生成を再実行
- **KPIダッシュボード**：初期投資額・年間削減額・年間純利益・投資回収期間・3年/5年ROI・NPV・IRRを、しきい値に応じた色分け（成功/警告/危険）で表示
- **コスト比較チャート**：現在のコストと導入後のコスト、削減額を棒グラフで比較表示（Recharts）
- **累積効果グラフ**：初期投資からの累積キャッシュフロー推移を損益分岐点の参照線付き折れ線グラフで表示
- **感度分析ヒートマップ**：月額利用料・システム導入費・自動化率・エラー削減率・従業員数の5パラメータについて、ベース値からの変動（±15%/±30%）がROI・投資回収期間・NPVに与える影響を色分けした表で表示（指標はセレクトで切替可能）
- **エグゼクティブサマリー自動生成**：提案要旨・主要財務指標・戦略的価値・推奨アクションをテンプレートベースで生成
- **レポートダウンロード**：エグゼクティブサマリーを含むMarkdown形式のレポートをブラウザ内でファイル出力

## 技術スタック

- React 18 + TypeScript
- Vite（開発サーバー・ビルド）
- Tailwind CSS（スタイリング、プライマリ/成功/警告/危険のカラーパレット定義）
- Recharts（棒グラフ・折れ線グラフの描画）
- React Hook Form（フォーム状態管理・入力バリデーション）
- ESLint（コード品質チェック）

## 実装の工夫

### 財務計算エンジン（`ROICalculator`）

- **年間純便益**：人件費削減（人員削減率・労働時間削減率・自動化率それぞれを現在の年間人件費に乗じて合算）、エラー削減・手戻り削減によるコスト圧縮、その他便益（機会損失削減・スケーラビリティ向上）を合算した年間削減額から、年間運用コストを差し引いて算出
- **NPV**：割引率8%（固定値）で、初期投資合計をマイナス起点とし、各年の年間純便益を `年間純便益 / (1 + 0.08)^年` で現在価値に割り引いて合計
- **IRR**：ニュートン-ラフソン法により反復計算（初期値10%、許容誤差0.0001、最大100回）。各反復でキャッシュフローの現在価値とその導関数を求め、収束するまでIRRを更新
- **ROI（3年/5年）**：`(年間純便益 × 年数 − 初期投資合計) / 初期投資合計 × 100` で算出
- **投資回収期間**：`初期投資合計 / (年間純便益 / 12)` により月数で算出

### 感度分析（`SensitivityHeatmap`）

- 5つの主要パラメータ（月額利用料、システム導入費、自動化率、エラー削減率、従業員数）ごとに、ベース値の−30%／−15%／ベース／+15%／+30%の5点を生成
- 各変動値でROIInputsのディープコピーを作成しパラメータを差し替えたうえで`ROICalculator.calculate`を再実行し、選択中の指標（3年間ROI・投資回収期間・NPV）の変化を計算
- ベース値からの変化率に応じて5段階（大幅改善〜大幅悪化）で色分けした表を表示し、指標はUI上のセレクトで切替可能

### リアルタイム再計算

- `react-hook-form`の`watch`でフォーム全体の値を監視し、`useEffect`で入力変更のたびに`ValidationUtils.validateROIInputs`を実行。バリデーションエラーがない場合のみ`ROICalculator.calculate`と`ReportGenerator.generateExecutiveSummary`を再実行し、タブを切り替えなくても最新の分析結果が反映される

### レポート生成（`ReportGenerator`）

- 投資回収期間とROI・NPVの組み合わせを条件分岐で判定し、「即座に導入を推奨」から「導入条件の再検討を推奨」までの推奨アクションを自動生成
- 概要・現状分析・財務分析・費用対効果分析・結論・推奨事項で構成されるMarkdown形式のフルレポートを生成し、ブラウザ上でBlobとしてファイルダウンロード
